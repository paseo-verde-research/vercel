Area shows concentration

Larger rectangles contain more raw nonblank source lines, including comments. This is a view of code concentration, not complexity or a recommended AI context size.

A useful starting point

Inspect exact totals, direct files, and language proportions. The folder guide offers tasks to copy into Badger; related files elsewhere may still be needed.

One file, offline

Your report embeds relative paths and aggregate metadata, not source contents. Open it directly from disk. Share it when you intend to share its paths, filenames, and counts.

Map your own repository

Use badger map for the current directory or badger map /path/to/project for another directory. The HTML report is written to your current working directory.
