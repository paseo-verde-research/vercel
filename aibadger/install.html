Install AI Badger

Get started with the local-first CLI for AI code context.

curl -fsSL https://raw.githubusercontent.com/PVRLabs/aibadger/main/install.sh | sh

Installs to ~/.local/bin. Add it to your PATH if not already included.

Run in PowerShell 5.1+ on Windows. You may need to set your execution policy first.
