Why it exists

|
AI chats need context, but dumping a whole repository is noisy, risky, and hard to manage. Badger never sends repository content to an AI provider on its own. You decide what to share and where to send it.

Use AI Badger where you work

Use AI Badger from the command line or VS Code. The CLI provides the full repository-aware context engine, while VS Code brings file and Git-change workflows into the editor.

How a review works

AI Badger prepares the context locally. Your AI chat does the review.

1. Git changes

Start from the diff you already have, on the command line or in VS Code.

2. Focused context

Badger prepares a bounded, repository-aware payload locally.

3. Review in your AI chat

You paste into ChatGPT, Claude, Gemini, or another chat of your choice.
