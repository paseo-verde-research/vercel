Install StatLite

Install the latest binary on macOS or Linux with the shell installer or Homebrew.

Shell installer

Terminal
curl -fsSL https://raw.githubusercontent.com/PVRLabs/statlite/main/install.sh | sh

Installs to ~/.local/bin and verifies the release checksum. Add that directory to your PATH if needed.

Homebrew

Terminal
brew install pvrlabs/tap/statlite

Run StatLite

With your Spring Boot application running, create a configuration and start StatLite:

Terminal
statlite inspect 'http://localhost:8080' --create-config ./statlite.yaml
statlite

Open http://127.0.0.1:9090. Keep the dashboard on a private or protected network; StatLite has no built-in authentication.

Use Configure StatLite for other integrations, including HTTP monitoring for applications behind Caddy. See the installation documentation for version selection, source builds, and Linux service setup, or GitHub releases for binary downloads.

Docker alternative

Try the dashboard with its built-in self-monitoring configuration:

Terminal
docker run --rm \
  -p 127.0.0.1:9090:9090 \
  docker.io/pvrlabs/statlite:latest

Open http://127.0.0.1:9090. This disposable container removes its history when it exits. See the Docker guide for persistent storage, application networking, and version tags.
